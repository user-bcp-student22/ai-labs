# Hallazgos y matriz de seguimiento

## api

### Alcance y fuentes

- Discovery sin cambios de código. Base de evidencia: `HEAD` (`e52bc26`), que contiene el código original vulnerable.
- El árbol de trabajo tiene cambios sin commit en `api/app/main.py`, `api/app/files.py`, `api/app/repository.py`, `api/requirements.txt` y `api/tests/`. Se citan como "WT" cuando aplican. Según el paso, el estado inicial de todas las filas es `Pendiente`; los cambios WT no están verificados con pruebas.
- Ausentes: `docs/ENDPOINTS.md`, `docs/TESTING.md`, `PLAN.md`. `prompts/` de la raíz está vacío. Por eso el contrato se deriva del código abajo.
- Ninguna fila de `RETO.md` (sección api) resultó "No encontrado".

### Contrato observado (derivado del código; sin docs/ENDPOINTS.md)

| Ruta | Autenticación | Entrada | Salida observada | Evidencia (HEAD / WT) |
|---|---|---|---|---|
| GET /api/tasks | Bearer | query `owner` opcional | lista de tareas ordenada por id | api/app/main.py:68 / api/app/main.py:90 |
| POST /api/tasks | Bearer | JSON `title`, `description`, `status` (TODO), `priority` (MEDIUM), `owner` (identidad) | 201 con la tarea creada | api/app/main.py:78 / api/app/main.py:96 |

- **Flujo del token (HEAD):** el header `Authorization: Bearer <b64>` se decodifica en Base64 a `usuario|rol|exp|secreto`. Se valida que haya 4 partes, que el secreto sea igual a `LEGACY_SECRET` y que `exp` no haya vencido (api/app/main.py:17-26). WT: api/app/main.py:28-42, misma lógica con `ValueError` y log de advertencia.
- **Acceso a SQLite (HEAD):** una conexión global por app (api/app/main.py:35), tabla `tasks` creada e inicializada con tres filas de ejemplo (api/app/main.py:37-43). Las consultas se arman por concatenación de strings (api/app/main.py:70, :84, :87, :93). WT: consultas parametrizadas en api/app/repository.py:3-23.
- **Carga de archivos (HEAD):** `file.filename` se une directamente a `WORKSHOP_UPLOAD_DIR` y se escribe con `write_bytes` (api/app/main.py:109-111). WT: nombre normalizado, extensión permitida y límite de 5 MB en api/app/files.py:5-16 y api/app/main.py:126-133.
